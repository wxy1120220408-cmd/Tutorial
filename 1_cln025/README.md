This code represents the demonstration workflow for WE-MLCVs. This directory contains 1 subdirectories and the files within them.

- **1_cln025**: Code and input files for CLN025 training and simulations.
    - **0_dwt**: For removing fast modes from trajectories and performing feature selection based on wavelet coefficient energy and correlation.
    - **1_training**: Training WE-MLCVs using the subset of wavelet-enhanced descriptors.
    - **2_sampling**: Performing OPES simulations using WE-MLCVs.
